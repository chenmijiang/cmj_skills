# cmj_skills

This repository contains reusable AI agent skill definitions for daily personal use.

## Directory Structure

```
cmj_skills/
├── LICENSE                 MIT License
├── README.md              Project Overview
└── skills/                Collection of Skill Modules
```

Each skill directory contains:
- `README.md` - Human-readable overview and use cases
- `SKILL.md` - Complete skill content and instruction format
